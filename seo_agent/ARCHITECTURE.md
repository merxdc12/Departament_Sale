# SEO Agent — Sales Learning Architecture

## Business objective
Account safety → product relevance → search visibility → click → sale → profit → learning.

## Agent responsibilities
1. Design/Product semantic analysis
2. Buyer Intent classification
3. Long-tail keyword generation
4. Keyword clustering: Product / Audience / Theme / Occasion / Style / Intent
5. Demand-vs-competition scoring
6. Platform-specific SEO skills
7. Semantic SEO / AI-search discoverability
8. SEO Critic before publication
9. Performance feedback after publication
10. Learning from CTR, conversion, orders and profit

## Hard gates
- IP / trademark: fail closed
- US auto-publication: official USPTO verification required by project policy
- account integrations: official API/OAuth only when available and approved
- no CAPTCHA bypass, dashboard scraping, cookie cloning or rate-limit evasion
- conservative SAFE PACE for allowed API activity

## Feedback loop
DESIGN → SEMANTIC PROFILE → KEYWORDS → SEO SCORE → IP/USPTO → LISTING → PERFORMANCE → PROFIT → LEARNING → NEXT LISTING

## Learning signals
A keyword or cluster is not considered successful merely because it generated impressions.
The learning engine must distinguish:
- visibility: impressions
- attraction: CTR
- commercial intent: conversion/orders
- business value: profit

Final optimization target: profitable sales, not listing volume.
